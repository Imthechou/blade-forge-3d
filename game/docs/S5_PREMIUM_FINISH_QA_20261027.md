# S5 工艺签名与柔光影棚 · 验收记录（2026-10-27）

## 本轮方向
参考 CS2 真实刀皮的工艺分类、纹理方向性和环境反射原理；没有复制参考网站的模型、贴图、Shader 或代码。本项目保留自身 WebGL2 固定 Shader program family 与 GPU 预热架构。

先前的 S5 会让不同工艺使用相似的分形色斑，只替换调色板。现在按卡牌的 **finishCardId** 选择本阶段的唯一工艺族，种子只能改变图案布局或宝石子色，不能在后续阶段随稀有度任意串色。

| S5 卡 | 族 | 空间规律与 PBR |
|---|---|---|
| S5_14 液氮断彩 | Marble Fade | 连续变形红蓝金带纹 + 平整高反射 |
| S5_16 赤金临界 | Case Hardened Gold | 金铜氧化岸线和部分蓝钢，保留钢色留白 |
| S5_18 横贯热带 | Case Hardened Blue | 蓝金金属岛；少数 seed 进入蓝宝石式稀有模版 |
| S5_19 幻彩氧层 | Fade | 刀根到刀尖连续紫红金渐变，不重复周期彩斑 |
| S5_20 蓝紫流界 | Doppler | 连续液态蓝紫流纹，不是彩色圆点 |
| S5_21 神淬虹纹 | Gem Doppler | 种子稳定确定 Ruby / Sapphire / Emerald / Black Pearl 的同色系深浅 |
| S5_23 冷热虹界 | Base Fade | 保留之前已确认的随材料基色变化的冷暖渐变设计 |
| S5_25 静镜留底 | 中性抛光 | 保留底材，不引入高级工艺调色板 |

普通工艺保持原有算子；高级 S5 族只接管 S5 当前已选择的颜色和精抛粗糙度。刀身的 S3 锻纹和种子继续继承；S6 回火仍是后置轻薄膜层。所有新族仍使用原有四个调色板 uniform 与现成 FBM，未新增贴图、下载资产或逐卡宏变体。

## 柔和影棚
- 扩大两盏柔光箱角尺寸，降低过亮主光亮核，保留反射线条。
- 提高环境基础亮度与柔和正面补光，避免黑色旗板把暗部打成死黑。
- 保留 HDR HalfFloat PMREM 和 iOS fallback；没有切成 8-bit LDR 假 HDR。
- 校准目标是压缩极端反差，而不是整体加亮或者关闭金属反射。

### 验收范围边界
- 截图全部来自 WebGL Chrome；iPhone 浏览器布局及 HDR 回归**不能替代实体 iPhone Safari GPU 真机目测**。
- S5 代表工艺主要在固定的 kris 刀型上对拍；S4 24 卡检查了几何与锻纹，但不等于 S5 所有工艺 × 12 刀型的穷举视觉验收。
- 这些效果为原创 WebGL 近似工艺，并非对 CS2 引擎或 Valve 资产的逐像素复刻。
