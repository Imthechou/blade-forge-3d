## 二、根因：`uV2Proc` 只进了颜色层

这是 P3 真正的问题，和计划里写的「走 uV2Preserve 分支只做染色」是同一件事，
但更精确：

```
uV2Proc 的四个分量  →  只有 MAP_FRAGMENT（颜色）读它
                    ✗  ROUGHNESS_FRAGMENT  从未读过
                    ✗  METALNESS_FRAGMENT  从未读过
                    ✗  normalFragment      从未读过
```

实测证据（`_p3probe.mjs` 基线）：
**S1 矿石的 `uBladeMetalness = 0.92`，和成刀完全一样。**
矿石被渲染成了抛光合金 —— 而这正是「石头质感」抱怨的来源。

所以 P3 不是「加效果」，而是**让已有的三个分量真正流到该去的地方**。

## 三、实测数据

### 3.1 阶段表（改动前 → 改动后）

采样：390×844@DPR2，`preserveDrawingBuffer:true`，每阶段强制 `renderer.render()` 后读帧，
相位自检连续两次读帧一致才算有效（`stable=true`）。

`hlEnergy` = `mean(max(0, L-0.70)^2)` 高光能量
`hiPct` = luma > 200 的像素占比
`hfEnergy` = `mean(|Laplacian(L)|)` 表面高频结构能量

| 阶段 | 模型 | hlEnergy | hfEnergy | 对比σ | 是否达标 |
|---|---|---|---|---|---|
| **S1 原料** | ore_small | 0.002735 → **0.000599** (−78.1%) | 0.106381 → **0.157938** (+48.5%) | 0.2666 → 0.2065 (−22.5%) | 取舍 |
| **S2 熔炼** | molten_sphere_small | 0.007825 → 0.006894 (−11.9%) | 0.056694 → **0.063391** (+11.8%) | 0.2490 → 0.2477 (−0.5%) | 持平 |
| **S3 锻打** | blank_ingot_small | 0.000643 → **0.000985** (+53.2%) | 0.126525 → **0.197652** (+56.2%) | 0.1605 → **0.1808** (+12.6%) | **PASS** |
| S4 定型 | knife_kris | 完全不变 | 完全不变 | 完全不变 | 不在作用域 |
| S5 淬火 | knife_kris | 完全不变 | 完全不变 | 完全不变 | 不在作用域 |

**S3 是本轮唯一「三项指标同向上升」的阶段** —— 高光能量、表面结构、整体对比度一起涨，
说明锤痕（几何）+ 各向异性（高光拉成线）+ 粗糙度调制（散反射）三层确实协同了，
不是某一项数字被调上去。

**S4/S5 全零差异是好事**：证明 P3 的分支隔离干净，成刀 PBR 链一点没被碰到。

### 3.2 S2 钢液流动（计划验收条款，独立验证）

`_p3time.mjs`，16 个样本 × 250ms，**不强制重绘**：

```
时钟推进 Δt = 3.289s
亮度       min 0.44960  max 0.48409  mean 0.47118  sd 0.01151
相对振幅   A = 7.320%
高光能量   相对振幅 = 11.98%
判定 · 时钟推进   PASS
判定 · 亮度波动   PASS
```

高光能量振幅（11.98%）远大于漫反射振幅（7.32%）是**预期**的：
高光只响应法线变化，所以同一个几何流动在高光里的可见度更高。
这也说明差异来自法线层，不是来自整体亮度漂移。

### 3.3 顺带发现的既有缺陷：`_p3base.mjs` 的基线是假的

原有基线 `shots/p3/_rows.json` 里 **S1 与 S2 的像素统计完全相同**：

```
S1 lumMean 0.621  lumStd 0.218  satMean 0.221  hueHist 精确到 0.1% 全等
S2 lumMean 0.621  lumStd 0.218  satMean 0.221  hueHist 精确到 0.1% 全等
```

而两者模型分别是 `ore_small` 与 `molten_sphere_small`，几何根本不同。
根因：`viewer._isAnimating()` 为假时 `pauseRender()`，画布停在**上一阶段**的最后一帧，
而原脚本固定等 900ms 就去读 —— 读到的是旧缓冲。

**因此旧的 `_rows.json` 不能作为 P3 的「改动前」对照**，本轮全部重测。
`_p3base.mjs` 保留未删（历史证据），但不要再引用它的数字。

## 四、我错了 5 次（全部记录）

### 错误 1：以为旧基线能用

做法：直接读 `shots/p3/_rows.json` 当 before。
结果：写代码前先核了一下，发现 S1/S2 数字全等 —— **基线是脏的**。
代价：必须先重写测量装置，才敢动一行 shader。
教训：**测量装置本身要先验证。** 两个不同的模型给出完全相同的六个统计量，
概率上不可能，这是装置坏了而不是巧合。

### 错误 2：`hlEnergy` 这个指标根本不存在

计划写「S1–S4 各阶段 `hlEnergy` 提升 ≥20%」，但全项目搜索 **0 处实现**。
做法：新定义两条与项目既有口径对齐的指标（`hlEnergy` + `hiPct`，后者沿用
`tools/probe-handle-dr.mjs` 的 luma>200 约定），并写进脚本注释。
教训：验收条款里的指标名如果搜不到实现，它就不是验收条款，是愿望。

### 错误 3：把矿石金属度压到 0.55

做法：按「矿石是半金属」直接把 S1 金属度乘 0.55 → `metal ≈ 0.51`。
结果：**hfEnergy 从 0.1064 掉到 0.0905、σ 从 0.2666 掉到 0.2058** —— 石头变平了。
根因：S1 原来的高频细节几乎全靠「金属镜面反射小面积高亮光源」撑
（P2 好不容易做出来的摄影棚环境）。一旦不是金属，镜面退场，
石头就只剩一片均匀漫反射 —— 那不是石头，是塑料。
修法：下界改 0.72（`metal ≈ 0.66`，真半金属），并同时做错误 4。

### 错误 4：以为降金属度就够了

接错误 3 —— 只调金属度是把 S1 往「均匀塑料」方向推。
真相：石头在漫反射下的层次必须由**几何碎面 + 颜色碎面**共同提供。
两处一起补：
- 几何：`STAGE_RELIEF[0]` 0.075 → 0.45（P2 的「别太糙」结论只对抛光成刀成立）
- 颜色：碎面幅度 `0.80+0.42` → `0.68+0.62`
结果：hfEnergy **0.1064 → 0.1579 (+48.5%)**，比改动前的结构还强 48%。

### 错误 5：把 S2 的流动振幅算成 33.865%

做法：16 个样本全丢进统计。
结果：**33.865% 是假的。**
证据：`#0–#2` 的 `effectTime` 恒为 `0.000`、`lumMean` 恒为 `0.61867`（三位小数不变），
从 `#3` 起才 `8.759 → 12.137` 前进 —— 前三个是**材质尚未应用时的陈旧帧**。
把陈旧帧算进去等于拿「另一个画面」跟「钢液」比，不是流动。
修法：按 `effectTime` 严格递增剔除热身帧，重算得 **7.32%**（真实值）。

> 教训与 P2 的「帧数不等于时间」是同一条：
> **时序指标必须先判「时钟到底在不在走」，再谈波动幅度。**

## 五、计划本身的 2 处自相矛盾（如实记录）

### 矛盾 1：hlEnergy ≥20% vs「S1 降低 metalness」

`MATERIAL_PLAN.md` P3 节同时写了：

```
验收：- S1–S4 各阶段 hlEnergy 提升 ≥20%
做法：- S1 原料：提高法线强度 + 降低 metalness（矿石是半金属）
```

降金属度**必然**压低镜面高光能量。这两条不能同时满足。
我选择服从「做法」（语义正确：矿石不该像抛光合金），
所以 S1 的 hlEnergy 是 **−78.1%**，判定为 **FAIL（计划条款）**，不粉饰。

### 矛盾 2：S4 根本不是过程模型

计划写「P3：S1–S4 过程模型专属曲线」与「S4 定型：锤痕被压平」。
实测：`PROCESS_MODELS = ['ore_small', 'molten_sphere_small', 'blank_ingot_small']`，
**S4 定型用的是 `knife_kris`，`preserve = 0`**，走的是完整成刀 PBR 链。

**P3 的真实作用域是 S1–S3，不是 S1–S4。**

## 七、未达成（如实记录）

1. **S1 的 hlEnergy 下降 78%，且 σ 下降 22.5%。**
   这是「矿石不该是金属」的必然代价，但**代价确实落在对比度上**。
   hfEnergy +48.5% 说明结构是有的，可是整体对比σ 变平了。
   → 未解决。下一步应当从**环境/光照配比**入手，而不是继续推法线
   （P2 已证明「拉高强度只会过曝」）。

2. **没有任何人眼视觉验收。**
   本轮全部结论来自像素统计。`hfEnergy` 只能证明「有结构」，
   **不能证明「看起来像矿石/钢液/铁」**。
   对照 P2 的第 5 节：P2 的结论是「人眼逐张判断是唯一标准」。
   P3 目前**没有这一层证据**，只有数字。

3. **S2 的流动只有 7.32% 亮度振幅。**
   数字上过判据（>0.5%），但 7.32% 是否「看得出在流」未经人眼确认。
   高光振幅 11.98% 是更可信的信号，因为它只响应法线。

4. **S5 之后、以及 S4 定型没有任何 P3 改动。**
   按计划它们不在作用域内，但这意味着「从胚体到刀身」那一步
   （S3 → S4）的观感落差仍是原始状态。

5. **移动真机仍未测**（继承 P2/T15 的缺口，非本轮新增）。

## 八、下一步建议

按 `MATERIAL_PLAN.md` 的顺序，**P4（Pattern 多层合成）** 是既定下一步。
但基于本轮实测，我建议**插一个 P3.5**：

```
P3.5：S1 的环境/光照配比（不加法线，不改金属度）
  理由：S1 的 hfEnergy 已经有 +48.5%，但 σ 掉 22.5% ——
        结构够了、明暗反差不够。继续加法线只会更糊。
        该动的是「漫反射占比 vs 环境强度」的配比。
  证据：_p3probe.mjs 的 S1 行；P2 `_light3.mjs` 已证明拉强度会过曝。
  验收：S1 的 σ 回到 ≥0.24，同时 hfEnergy 不低于当前 0.1579。
```

然后才是 P4。理由：P4 是「同阶段内不同的卡要一眼可辨」，
而 S1 现在连**自己该是什么样**都还没定稳，先做卡间差异会把问题放大。
