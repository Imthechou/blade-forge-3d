# 锻刀大赛 · S1–S10 统一视觉链路与工艺设计规范 v1.0

> 2026-10-27。设计基线与实施验收标准，**不代表代码已经按本规范改完**。保留现有 v2 Shader 固定程序族、GPU 预热缓存、iOS HDR 半浮点反射、移动端一屏布局；本规范不调整数值、风险、存档与赛事。

## 一、已确定的共同约束

- S4 为 **12 种刀型、24 张卡**：K01–K12 普通款，K13–K24 高级光晕款；每种刀型各有一张普通、一张高级。普通款重刀型轮廓和金属体积；高级款保留同一刀型模型，追加独立配方的刃缘/轮廓光晕，史诗以上可以有克制的扫光与呼吸。
- S1–S9 每张卡必须有独立、符合工艺含义的 3D 结果。**没选就没有，选过必须继承**。后续卡只能修改本阶段拥有的外观层，不得重新随机涂改前一阶段。
- 先改变几何与表面结构，再改变粗糙度/反射，最后才是克制染色；不能只靠彩色线条、全刀洗色和随机亮度制造卡牌区别。
- 刀身 Blade、护手 Guard、握柄 Grip 至少三种独立区域；装配前可维持统一钢材预览，S8 明确选择握柄后才切分材质。护手默认继承刀身金属，除非卡明确给了护手配方。
- 材质视觉应参考 CS2 高级刀皮的 PBR 分层，但不牺牲 WebGL 移动端性能和同一张卡的可复现性。

## 二、阶段视觉职责表（设计目标）

| 阶段 | 进入时的基础形态 | 选卡最主要的视觉变化 | 锁定的层 / 禁止事项 |
|---|---|---|---|
| **S1 原料** | 矿石 ore_small，raw 机位 | 材料色、金属度、矿脉/结晶面、自然断裂和高光不同；24 种材料要有真实身份 | 锁 Material 基础。不能先出现 S3 锻纹、S5 彩色工艺 |
| **S2 熔炼** | **进入阶段即显示中性熔体** molten_sphere_small，melt 机位，保留 S1 材料基色 | 冷热热泽、纯度、流动/夹杂、液面反射和均质程度；候选区别主要靠流线和清浊，不靠随机花纹 | 锁 Melt 加工记忆。熔体动态为过程特效，不得提前开启 S3 纹理 |
| **S3 锻打** | **进入阶段即显示中性刀胚** blank_ingot_small，billet 机位，保留 S1/S2 | 锻纹的层级/方向/尺度/深浅、法线起伏、局部粗糙度：大马士革、锤痕、拉丝、波纹等真正形态不同 | 锁 Pattern + Height/Normal/Roughness + 种子。不能用橙色平行线代替所有纹理 |
| **S4 定型** | 未选卡仍为刀胚；选卡切对应 knife_* 全刀，forge 机位 | 12 种刀型的真实轮廓/截面/厚度，普通+高级共 24 卡；高级专属 Halo、刃缘亮线与可选扫光 | 锁 KnifeType + S4 卡特效。完整继承 S1–S3 的金属与锻纹，不能换刀时刷掉花纹；自由落锤独立反馈 |
| **S5 淬火** | 已成型刀、edge 机位 | 刀身主工艺质变：抛光/氧化、镜面反射、表面淬火斑、Doppler、Fade 等；仍读得出原有钢材和 S3 纹理 | 锁 Finish + 该卡稀有工艺配方。中性工艺不染色；Fade 可在刀身大范围渐变，但绝不跨区域染握柄 |
| **S6 回火** | S5 的已确认刀皮、temper 机位 | **薄层、低透明度**的氧化膜、细窄色带、视角虹彩与柔和光泽；改变膜厚/局部覆盖/运动，而不是重做底色 | 锁 Temper Film。不得重新涂掉 S5 刀皮或盖住 S3 纹理 |
| **S7 开刃** | 刃口放大，grind 机位 | 刀型相关的真实刃口宽窄/折面/倒角/磨痕与刃线高光；小游戏结果决定完成质量 | 锁 Edge 区域和 grind 子参数。不能靠全刀霓虹描边、不能上色到柄 |
| **S8 装配** | 完整成刀、assemble 机位 | 握柄/护手/尾部的材质、包覆、纹理与细微金属构件明显变化；高级卡细节更精致 | 锁 Handle/Grip，显式 Guard 时才覆盖护手。刀身/S5/S6/S7 已确认外观不动 |
| **S9 调校** | 完整成刀细节、tune 机位 | 局部磨损、细刻线、精抛拖痕、结构微调、饰面收尾；效果克制但可辨 | 锁 Wear/Tune 局部微结构。不能把刀变成新刀皮或粗布纹 |
| **S10 鉴定** | 完成的全刀、reveal 机位 | 同一份最终 PBR 配方，仅变镜头、展示角度、评分揭晓 UI | 冻结最终状态；鉴定/工坊/收藏卡复用，不重新 roll 种子或选特效 |

**重要交互调整**：当前代码在 S2/S3 刚进入时展示上一阶段的矿石/熔体，点第一张卡才换为熔体/刀胚。这会把「进入工序的几何变化」误当成「卡牌带来的视觉变化」。目标改成：**进入 S2 即中性熔体；进入 S3 即中性刀胚**，但当前阶段特效仍未激活。S4 选刀型前必须保留刀胚。

## 三、统一的外观合成和部件所有权

外观合成依次是：

1. 全局稳定的 HDR 摄影棚与曝光（不受任一候选卡随机改变）
2. S1 基础材质（Base Material）
3. S2 材料状态记忆（Melt Memory；过程动态仅属于熔体）
4. S3 锻纹、粗糙度和法线（Pattern/Relief）
5. S4 刀型 Mesh + RegionMask + 可选高级 Halo
6. S5 刀身主表面工艺（Finish）
7. S6 低覆盖薄膜（Temper，保留 S5 底层）
8. S7 真实刃口（EdgeMask）
9. S8 分部件装配（Grip；显式指定时 Guard/Pommel）
10. S9 局部 Wear/Tune，S10 只读冻结

所有权原则：材料、纹理、刀型、工艺、薄膜、刃口、装配和磨损是**互不重写的独立层**。已有游戏逻辑里可使用同一个 Shader，但 uniform 和 mask 必须有明确所属工序；通用阶段色相、全局最高稀有档和旧装饰纹样不得抢改已锁定层。

**稀有度**：S4 高级 Halo 必须由 S4 卡决定，S5 经典刀皮表现由 S5 已确认卡决定，S6–S9 不允许把 S5 的强度/颜色重新按自己那张卡的稀有度计算。全局最高视觉档只可作为全局展示信息，不可回灌已确定的阶段。

**固定种子**：S1 底材、S3 花纹、S5 Finish 和后续每层的随机性要能按 run seed + stage + cardId 复现；一次锻造过程中的候选反复切换不能让已确认的图案跳变。

**区域**：S4–S7 保留现有刀身钢材覆盖的演进效果；S8 装配后刀身仍继承 S5/S6，握柄切至新材质；护手独立且只按**明确选择**启用，不能悄悄变回灰色；刃口特效只在 EdgeMask。

## 四、用户选卡的四态协议

- **Enter**：加载本阶段中性工序模型和镜头；保留先前确认的所有材料效果，不激活未选卡。
- **Preview A/B/C**：以不可变的 confirmedSnapshot 为基准，**只替换本阶段临时覆盖层**；点 B 不叠加 A；其它阶段图案、Seed 和 Shader program 不变。
- **Cancel/Reroll**：完全恢复本阶段的初始 confirmedSnapshot，并取消异步旧预览（包括模型、光晕、柄 Mask）。
- **Commit**：仅提交玩家选择的本层配方；确定性地进入下一阶段；预览效果与确认结果一致，确认时不得重新随机变色。允许镜头和工序几何变化，但材料身份不变。

阶段之间视觉反馈要能辨认「成功进入下一工序」，不可用无关的大面积闪屏代替工艺变化。每阶段三张卡的视觉差异优先来自工艺结构，然后是反射，再是色彩、稀有附加效果。

## 六、实现边界和验收清单

**P0 先保正确性**：先把配方责任、阶段进入基础形态、已确认状态、预览撤销、稀有度归属与区域 Mask 对齐。暂不重写 Three.js、programFamilies、GPU 缓存架构；任何 Shader 源码更改遵守 FAMILY_VERSION 与预热签名规则。

**P1 再做观感**：优先精修 S3 的真实纹理、S5 的 CS2 级金属反射/色层、S6 的轻薄叠加；其次 S4 高级光晕、S7 倒角、S8 装配、S9 微结构；再做 S1/S2 的专项细化。

**浏览器实测**：固定种子，S1–S9 每阶段截取未选态、A/B/C 三卡、取消、确认后的画面和配方快照；S4 额外跑全 24 张候选卡。确认以下不变量：

- S2/S3 未选卡使用本阶段中性模型，纹理选项不能提前生效；S4 未选保持刀胚。
- S3 纹理在 S4 定型后仍能辨识；S5 选择后直到 S10 不会被后续卡莫名改色；S6 保底色。
- A→B→C→取消→A→确认，最终材质/随机参数与第一次 A 预览相同；不发生迟到的旧 GLB/Shader 覆写。
- S4 恰好 12 个普通无 Halo + 12 个高级有对应 Halo。特殊光晕不串到另一种刀型，也不串回普通刀。
- S8 切卡时仅部件材质更动，刀身和刃口的已确认参数与图案不变；S9 只局部变化。
- 真实 Chrome 手机 390×844、390×740 及桌面出图，同时复验 iPhone Safari 的 HDR 反射与一屏操作；0 JS 错误，切卡缓存与 Shader program 数不退化。定量差异只作辅助，必须逐卡目视排除“卡名和效果对不上”。
