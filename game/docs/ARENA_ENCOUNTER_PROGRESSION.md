# 赛事关卡编排 V1.2 · 固定靶具强度

## 目标与边界
- **六种靶具的物理强度固定**：`arenaChallenge.MATERIALS` 的 `armor / hard / health / damage / angle / points` 不随赛事层级、局内阶段或路线选择变动。新靶具 `difficulty = 1`，不再在压轴冲刺临时加厚；同靶同刀的破甲、切入进度与受损一致。
- 难度只在 **可出现材料组合、投放节奏、每段投放配额、在场数量** 上递增；刀自身的六维能力和技能仍影响切割质量。
- 不改锻造 S1-S9 的材质、渲染与刀具记录。赛事切割仍共用 `arenaChallenge` + `arenaStage`。
- 快速挑战保持45秒训练赛和原有投放节奏；正式赛事（学徒至巅峰）使用下述独立编排。

## 六种靶具固定难度排序

`泡棉 → 绳束 → 木桩 → 工程塑料板 → 透明冰块 → 实心合金金属块`

轻靶一划可断；木桩开始涉及破甲和补刀；金属块反作用最高。数值直接读 `arenaChallenge.MATERIALS`，本文不复制或修改它们。

## 45 秒四阶段

| 阶段 | 游戏内时间 | 规则 |
|---|---|---|
| 热身 | 0–8秒 | 出场3靶，低档以软靶为主，高档可提前上硬靶 |
| 路线 | 8–23秒 | 选连切/穿透/硬核路线后，按难度投放；连切路线偏低阶材质，硬核路线偏高阶材质 |
| 提速 | 23–30秒 | 自动提速，材料上限提高，当前阶段配额独立计算 |
| 压轴 | 30–45秒 | 玩家选稳健/冲刺；稳健优先较软的当前等级靶池，冲刺优先硬靶，不改变单靶强度 |

选择路线/压轴以及手动暂停期间计时冻结。每阶段的 `quota` 是**计划最大出场数**，并发位满时延后投放，不超过配额；上一阶段未切靶具可以自然留在场上直到其原有存活时长到期。四段实际发生数见 `run.encounterHistory`。

## 验收标准

- `npm test`：13个赛事档位的配额、解锁阶段单调递增、生成对象数不超过配额、`difficulty=1`、MATERIALS 常量不变；对六种材料分别比较学徒与巅峰的同刀切入和反作用，必须一致。
- Chrome/Playwright 移动视口：快赛完整45秒结算、流派赛一局45秒结算、全国及巅峰赛实际入场并能滑切，核对赛级与开场配额及靶具。
- 原有锻造可视化验收不得因本变更失败。

## 后续调优（不在本轮）

在真实 iOS/Android 上根据平均切断数、漏切率、单局帧率和每段是否经常刷空，微调**配额、并发数、材料权重**，禁止直接随赛级增加材料 `armor`/`health`。非切割小游戏与赛事视觉是独立课题。
