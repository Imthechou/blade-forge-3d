# 赛事 V3 实现与验收

新赛统一为 45 秒切割；开局、15 秒、30 秒同品质三选一，选择期间冻结时间。
流派赛每场一局，全国赛一刀五轮，巅峰赛三把不同成刀各打一轮，强化与临时刀况每轮重置。
规则版本 `arena-3` / `formal-3`。旧藏刀六维、外观、鉴定分与存档版本保持兼容；新快赛纪录以 `quick:v3:*` 分组，保留旧纪录。

## 数值

数值真源为 `src/data/balance.js` 的 `ARENA_V3`、`ARENA_MATERIALS`、`ARENA_POWER`。
永久六维在赛事内使用独立的 0–150 曲线，150 以上软饱和，不重算鉴定或锻造属性。
锋利、强度、工艺决定切入；韧性与设计决定损耗；灵性提高强化共鸣收益。
刀型和特性分别参与切割、精准、破甲、耐久适配，不在结算时再乘一次属性分。

固定 400 个手势样本：角度误差 ±0.9 弧度、中心误差 0–0.057、划切时长 0.16–0.34 秒；
中性刀型、无强化。没有独立的随机斩断概率。材料变化只为固定的轻微个体差异。

| 均值 | 泡棉首刀断率 | 金属平均切数 | 击破金属累计刀损 |
| --- | --- | --- | --- |
| 60 | 54.25% | 14.6 | 65.8 |
| 100 | 100% | 5.2 | 12.4 |
| 150 | 100% | 2.0 | 2.1 |

样本数据用于可复现标定，不代表真人移动端总体成功率。偏科刀另有回归测试。
高级赛事增加材料比例、目标密度、移动阵型和公开目标分，不增加同材料的护甲/生命/单击反作用。
每局开场 3 个目标，通常 3–5 个，最多 6 个；击破 0.15 秒后补位，不因整段预算用完而空场。
材料存在 3.6–8 秒，已有切入时最多延长 2 秒。连续按压满足 0.16 秒与 0.12 行程后可再次命中同一目标。

## 构筑与评分

36 张强化：10 银 / 16 金 / 10 棱彩。五种共鸣：连斩、精准、破甲、裂变、险刃。
贯穿、冰裂传播、剑气与冰河连锁共用每划最多 3 个次级接触的预算。
次级击破仅给材料基础分的 35%，不生成精准、单划连击、狂热、回血或递归强化触发。
冰河连锁可传到相邻冰块，传播总数仍受同一个预算限制。

六流派按不同材料权重、阵型和操作奖励区分；同一切割结果直接用于正式赛胜负。
全国五轮分别偏向连斩、精准、破甲、综合、双风格。决赛按固定种子抽两种风格。
巅峰三轮为极致锋芒、不屈之刃、巅峰之作，严格校验阵容归属和每刀只出场一次。
刀况耗尽判负；正式赛事不新增永久断刀概率。

## 验证命令

```sh
npm test
npm run check
npm run ai:index
node tools/arena-v3-simulate.mjs > arena-v3-balance.json
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs CHROME_PATH=/path/to/chrome node tools/arena-v3-playtest.mjs
```

浏览器工具使用隔离存档、真实 PointerEvent、截图与录像。
主默认使用 Playwright 虚拟时钟推进 45 秒有效时间；设置 `ARENA_REALTIME=1` 可让快赛按真实墙钟运行。
其余比赛仍用虚拟时钟，切割分、刀损、晋级和强化全部由生产引擎结算，不注入分数。
工具默认自行启动本地服务；传入 `FORGE_URL` 时使用已启动的服务。

本轮 `npm test`：54 项通过，包含数值分层、偏科刀、0/15/30 暂停、补位、补刀、强化触发与上限、零操作、五轮推进、三刀轮换、存档与结算幂等。
`npm run check` 有仓库原有的 40 处缺失文档/诊断脚本引用，未新增此类错误；不以删除检查或补空文件掩盖缺失。
移动真机 GPU、发热、小时级长时间游玩未验证。手机视口与桌面软件渲染验收不能替代真机手感测试。
