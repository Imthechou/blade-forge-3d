## 设计不变量
1. 原始刀皮/纹理种子/六维/成刀评分不因磨合、工坊、临时 Buff 而更改。
2. 成刀卡在鉴定、藏刀阁、比赛派刀与赛报使用同一份 BladeRecord 展示模型。
3. 全局成长带来选择和控险，不让低品质刀通过无限升级替代锻造价值。
4. 所有结算事务先写盘再生效，同 matchId 重试不会二次领奖或增加磨合。
5. 移动端不能为每张收藏卡保留独立 WebGL renderer；沿用离屏截图缓存。

## P2 材料经济平衡约束（已实装）
- 只有 S1 原料卡需要库存；S2 工艺和 S4 刀型仍可通过工坊等级及永久解锁实现直选。
- **库存是确定性选材权，不是禁止随机选材的门票**。已获得库存的高级原料可以指定使用1份；随机抽中同款不扣除。旧版 unlockedCardIds 仍有永久权限。
- 有效正式结构赛的资格与现有 `qualifyingFormalMatch` 一致；快速挑战完成时间45秒且真实切中至少4个靶具；战报 ID 幂等，存档失败不掉落。
- 三刀队伍赛尚为旧规则，不伪装成 V4.1 结构赛；建议后续独立升级后再开启队伍磨合/掉落。
