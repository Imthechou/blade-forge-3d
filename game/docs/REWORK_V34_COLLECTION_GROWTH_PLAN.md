## 设计不变量
1. 原始刀皮/纹理种子/六维/成刀评分不因磨合、工坊、临时 Buff 而更改。
2. 成刀卡在鉴定、藏刀阁、比赛派刀与赛报使用同一份 BladeRecord 展示模型。
3. 全局成长带来选择和控险，不让低品质刀通过无限升级替代锻造价值。
4. 所有结算事务先写盘再生效，同 matchId 重试不会二次领奖或增加磨合。
5. 移动端不能为每张收藏卡保留独立 WebGL renderer；沿用离屏截图缓存。

## P1.2 正式三刀巅峰赛逐刀成长（2026-10-30）
- 结算使用官方 V4.1 Apex match 的唯一赛事 ID、三刀固定阵容与每轮完成详情。分刀记录只写入实际出场、出场顺序一致、状态 complete、结构进度 ≥20% 或目标完成的对应刀。
- 每把刀每届最多增加 1 场有效磨合，依然遵守熟刃 2 场+2%、名刃 5 场+5% 和永久六维/刀皮/评分冻结。保存时与整场 CR、XP、锻材和荣誉履历同事务；重复领奖不会重复成长。
- Apex 赛事战报对应轮次显示“磨合 +1”或“进度不足”；不重新定义三刀胜负，也不凭整体分数给未派出的刀奖励。
- 新增测试包含正向三刀参与、待命刀零经验、非法重复刀位、旧版记录、20% 阈值与存档失败后重试。旧 Team3 试验性规则保持原样。
