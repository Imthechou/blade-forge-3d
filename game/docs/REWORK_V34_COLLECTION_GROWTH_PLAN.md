## 设计不变量
1. 原始刀皮/纹理种子/六维/成刀评分不因磨合、工坊、临时 Buff 而更改。
2. 成刀卡在鉴定、藏刀阁、比赛派刀与赛报使用同一份 BladeRecord 展示模型。
3. 全局成长带来选择和控险，不让低品质刀通过无限升级替代锻造价值。
4. 所有结算事务先写盘再生效，同 matchId 重试不会二次领奖或增加磨合。
5. 移动端不能为每张收藏卡保留独立 WebGL renderer；沿用离屏截图缓存。
