# 锻造视觉 v1.2：阶段能量预算、S5 固定工艺族与全刀继承

2026-10-27 · 已根据实际 Chrome WebGL 测试校验；真机 Safari 仍需人工复核。本文是运行设计契约，不修改任何游戏数值。

## 为什么旧版会越锻越亮

原 v2 渲染同时存在：多阶段「色相色 + 亮度」混合；S6 以 `col += film * 3.10` 注入加法膜色；S9 再加一次颜色与 glow；最后有整刀 `col * (1 + 0.30 * shadowLift)`、材质环境补偿与 emissions。每道工艺本来应该改变材质微结构，叠在一起却变成了重复给刀打光。

现在采用统一预算：
- S1–S6 通用阶段色相按原像素明度归一化后混合，只改变金属颜色倾向，不连续增亮。
- S6 / S9 的薄膜使用低强度乘性调制，保留 S5 底色；S9 高级加光只读 S9 自己的卡级。
- 最终发光有硬上限，主材质的环境强度限制在安全带；仅压缩过亮高光，不抬全刀底色。
- **S4 高级刀型的独立轮廓光晕继续保留**，但不能被后续阶段稀有卡放大。

## S5：13 个工艺族 / 25 张决策卡

保留全部卡 ID、稀有度、概率、六维数值与风险，单一工艺仅有 1–2 张卡。随机种子决定纹理布局，不允许把卡随机换成其它工艺族。

| 工艺族 | 卡 ID | 核心视觉 |
|---|---|---|
| 中性镜面钢 | S5_25、S5_09 | 只调反射/微粗糙度，不染宝石色 |
| 冷淬钢 | S5_01、S5_02 | 冷调反射、清澈金属 |
| 哑光喷砂钢 | S5_03、S5_08 | 宽高光、细颗粒表面 |
| 锻流组织 | S5_04、S5_12 | 细长组织纹理、金属粗糙度 |
| 盐浴定色 | S5_05、S5_11 | 均匀细腻、少量冷暖偏色 |
| 发黑氧化 | S5_06、S5_17 | 深灰金属保留边缘反射 |
| 轻虹膜 | S5_07、S5_13 | 低覆盖氧化薄膜 |
| 枪灰氮化 | S5_10 | 枪灰、微金属结构 |
| 表面淬火 | S5_16、S5_18 | 金铜海岸线与蓝钢氧化岛 |
| 渐变之色 | S5_19、S5_23 | 刀轴单调连续过渡（另一张为原材色梯度） |
| 渐变大理石 | S5_14、S5_15 | 红蓝金流动宽带 |
| 多普勒 | S5_20、S5_22 | 蓝紫金属连续流纹 |
| 宝石多普勒 | S5_21、S5_24 | Ruby / Sapphire / Emerald / Black Pearl，整刀单色系深浅 |

S5 外观以**卡 ID**锁定。S1 底材再对镜面底色、色温、暗部深浅和微粗糙度作有限调节，同一工艺不失去身份。稀有度从普通到神话的品质梯度重点体现在：镜面整齐度、金属粗糙度、纹理完整性、工艺遮罩清洁度；不通过提高白光/自发光实现。

## S1–S8 区域强制合同

- **S1–S6 逐层应用于整刀**（Blade + Guard + 当前未装配的 Grip），S4 的定型只换几何与独立光晕。
- S7 开刃只改真实 EdgeMask（继续继承 S1–S6）。
- **S8 没选择时保持整刀钢材；明确选择刀柄材质后仅覆盖 Grip**。Guard 不是握柄，它应保持 S1–S6 的金属处理，除非未来明确设计专属护手卡。
- S9 的局部精修不能重新着色 S5 或替换刀柄；S10 鉴定只重用最终状态。
- 任何预览取消必须恢复相同颜色、纹理、底材、程序缓存状态。

## 真实浏览器 QA

- Node 测试：覆盖 25 卡恰好 13 族、1–2 卡/族、卡 ID 与种子稳定、不选无特效、稀有度微粗糙度品质递进、底材差异、S8 遮罩与亮度预算源码不变量。
- Chrome 390×844：24 张 S4 普通/高级 GLB 扫描，S5 全 25 卡逐卡截图，**M01/M06/M14/M24 × 五种高级工艺**共 20 张跨底材照片，验证 JS/GLSL 错误、WebGL 像素存在与 program 数。
- Chrome 全流程 S1–S9：三张卡选择、取消、确认、继承（含 S3→S4、S5→S8）。
- 当前固定种子观察到程序数量 **10**，没有新增工艺专属 program；不代表所有 iPhone GPU 都达到相同帧率。
- 浅色 M01/M14 的观感比深钢柔亮；高光使用有上限的肩部调制，避免为了压亮把暗钢变黑。真实 Safari 仍需按同样卡截图复核。

**剩余艺术任务**：现有模型的长轴与刀腹遮罩在不同刀型上不完全统一，部分 S3 锻纹仍显粗糙。进一步提升宜从贴图投射、结构法线和局部 PBR 开始，而非再次增加亮度。
